# 操作日志页面访问说明

## 问题排查

如果看不到"操作日志"页面,请检查以下几点:

### 1. 确认当前用户角色

操作日志页面仅对**领导角色(LEADER)**可见。

**检查方法:**
- 查看顶部导航栏右侧的用户信息下拉菜单
- 应该显示 "角色: LEADER" 或 "角色: 领导"

**如果显示的不是LEADER:**
- 请退出登录,使用领导角色账号重新登录

### 2. 测试账号

系统中预设的测试账号:
- **领导账号**: `leader` / `leader123`
- **员工账号**: `employee` / `employee123`

### 3. 重启前端开发服务器

如果刚刚修改了代码,需要重启开发服务器:

```bash
cd frontend

# 停止当前服务 (Ctrl + C)

# 重新启动
npm run dev
```

### 4. 手动访问路由

即使菜单中没有显示,也可以尝试直接访问URL:

```
http://localhost:5173/operation-logs
```

如果看到"403 Forbidden"或提示无权限,说明:
- 后端权限控制生效
- 当前用户不是领导角色

### 5. 清除浏览器缓存

```javascript
// 在浏览器控制台执行
localStorage.clear()
location.reload()
```

## 验证步骤

### 步骤1: 使用领导角色登录

1. 访问 `http://localhost:5173/login`
2. 输入用户名: `leader`
3. 输入密码: `leader123`
4. 点击"登录"

### 步骤2: 检查菜单

登录成功后,检查顶部导航栏:
- 应该能看到: 记账记录、资产管理、负债管理、统计汇总、**操作日志**
- 共5个菜单项

### 步骤3: 访问操作日志

点击"操作日志"菜单,应该能看到:
- 统计卡片(总记录数、创建/更新/删除操作数)
- 筛选条件(模块、操作类型、时间范围)
- 操作日志表格

### 步骤4: 生成测试数据

如果没有操作日志数据:

1. 去创建一个资产:
   - 进入"资产管理"
   - 点击"新增资产"
   - 填写信息并保存

2. 去创建一个负债:
   - 进入"负债管理"
   - 点击"新增负债"
   - 填写信息并保存

3. 去创建一笔交易:
   - 进入"记账记录"
   - 点击"新增交易"
   - 填写信息并保存

4. 返回"操作日志"页面,应该能看到刚才的操作记录

## 常见问题

### Q1: 菜单中没有"操作日志"选项?

**A:** 当前用户不是领导角色。请使用 `leader` 账号登录。

### Q2: 点击"操作日志"菜单没反应?

**A:**
1. 检查浏览器控制台是否有错误
2. 确认路由配置正确
3. 尝试直接访问 `/operation-logs` 路径

### Q3: 访问 `/operation-logs` 返回403?

**A:** 后端权限控制正常,但当前用户不是领导角色。这是预期行为。

### Q4: 操作日志页面是空白的?

**A:**
1. 点击"刷新"按钮重新加载数据
2. 检查后端服务是否正常运行
3. 检查操作日志表是否已创建
4. 查看浏览器控制台的网络请求

### Q5: 查看详情时没有数据?

**A:**
1. 确认操作记录的 `requestData` 和 `resultData` 字段有值
2. JSON数据可能在格式化时出错,检查控制台错误

## 总结

如果看不到操作日志页面,最可能的原因是:
1. **当前登录的不是领导角色** (最常见)
2. 前端开发服务器需要重启
3. 浏览器缓存问题

请按照上述步骤逐一排查。
