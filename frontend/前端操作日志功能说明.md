# 前端操作日志功能说明

## 功能概述

前端已完善操作日志查询功能,仅领导角色(LEADER)可以查看和管理操作日志。

## 新增文件

### 1. 类型定义
- `src/types/index.ts`: 新增 `OperationLog` 和 `OperationLogQuery` 接口

### 2. API 接口
- `src/api/index.ts`: 新增 `operationLogApi`,包含以下方法:
  - `getById`: 根据ID获取操作日志
  - `getRecent`: 获取最近操作日志
  - `getByUserId`: 根据用户ID查询
  - `getByModule`: 根据模块查询
  - `getByOperationType`: 根据操作类型查询
  - `getByTimeRange`: 根据时间范围查询
  - `getByUserIdAndModule`: 根据用户ID和模块查询
  - `getByUserIdAndOperationType`: 根据用户ID和操作类型查询
  - `getTotalCount`: 获取总数
  - `getCountByUserId`: 获取用户操作数量
  - `query`: 复合查询

### 3. 页面组件
- `src/pages/OperationLogList.tsx`: 操作日志列表页面

### 4. 路由和菜单
- `src/App.tsx`: 添加 `/operation-logs` 路由
- `src/components/Layout.tsx`: 添加"操作日志"菜单项(仅领导角色可见)

## 功能特性

### 1. 数据展示
- **统计卡片**: 显示总记录数、创建操作数、更新操作数、删除操作数
- **表格展示**: 包含所有操作日志字段的详细信息

### 2. 筛选查询
- 按模块筛选(资产/负债/交易)
- 按操作类型筛选(创建/更新/删除)
- 按时间范围筛选
- 组合查询

### 3. 详情查看
- 点击"查看详情"按钮打开抽屉
- 显示完整的操作日志信息
- JSON格式的请求数据和结果数据格式化展示
- 错误信息高亮显示

### 4. UI特性
- 模块和操作类型使用彩色标签
- 成功/失败状态使用彩色标签
- 支持分页
- 支持刷新功能
- 支持重置筛选条件

## 权限控制

### 1. 菜单权限
只有领导角色(`role === 'LEADER'`)才能看到"操作日志"菜单项。

### 2. API权限
所有操作日志接口都需要`LEADER`角色权限,后端已通过`@PreAuthorize("hasRole('LEADER')")`保护。

### 3. 角色判断
```typescript
const isLeader = user?.role === 'LEADER'
```

## 页面路由

访问路径: `/operation-logs`

## 使用流程

### 1. 领导角色登录
使用领导角色的账号登录系统(如: leader / leader123)

### 2. 导航到操作日志
点击顶部导航栏的"操作日志"菜单

### 3. 查看日志列表
- 显示最近的100条操作日志(默认)
- 包含操作人、模块、操作类型、状态、时间、IP等信息

### 4. 筛选查询
- 选择模块: 资产/负债/交易
- 选择操作类型: 创建/更新/删除
- 选择时间范围
- 点击"查询"按钮

### 5. 查看详情
- 点击任意记录的"查看详情"按钮
- 在右侧抽屉中查看完整信息
- 包括请求数据和结果数据的JSON格式

## 显示字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| ID | 日志记录ID | 1 |
| 操作人 | 操作人的姓名和用户名 | 张三 (zhangsan) |
| 模块 | 操作的模块 | 资产/负债/交易 |
| 操作类型 | 操作类型 | 创建/更新/删除 |
| 操作名称 | 具体操作 | 创建资产/更新资产 |
| 状态 | 执行状态 | 成功/失败 |
| 操作时间 | 操作发生的时间 | 2026-01-13 10:30:00 |
| IP地址 | 操作来源IP | 192.168.1.1 |

- **红色**: 失败

## 自动记录的操作

以下操作会自动记录到日志中:

### 资产管理
- 创建资产 (CREATE - ASSET)
- 更新资产 (UPDATE - ASSET)
- 删除资产 (DELETE - ASSET)

### 负债管理
- 创建负债 (CREATE - LIABILITY)
- 更新负债 (UPDATE - LIABILITY)
- 删除负债 (DELETE - LIABILITY)

### 交易管理
- 创建交易记录 (CREATE - TRANSACTION)
- 更新交易记录 (UPDATE - TRANSACTION)
- 删除交易记录 (DELETE - TRANSACTION)

## 响应式设计

- 表格支持横向滚动
- 抽屉详情页面宽度自适应
- 统计卡片在桌面端横向排列

## 性能优化

- 默认只加载最近100条记录
- 使用分页避免一次性加载大量数据
- JSON数据懒加载,点击详情时才格式化显示

## 错误处理

- API请求失败时显示错误提示
- 401未授权时自动跳转到登录页
- 操作失败时在详情页显示错误信息
